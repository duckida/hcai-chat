# AGENTS.md - Coding Agent Guide for HCAI Chat

This document provides an overview of the codebase, architecture, and development environment for coding agents working on the **HCAI Chat** application.

## 🚀 Project Overview
HCAI Chat is a modern AI-driven chat interface built with **Next.js (App Router)**, featuring real-time streaming, web search integration (Exa), and an "Artifacts" system for displaying structured content/code generated by the AI.

## 🛠 Tech Stack
- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS v4, Shadcn UI, Lucide React, Framer Motion
- **Language**: JavaScript (ESM)
- **API/Backend**: Next.js API Routes (Serverless)
- **Search Integration**: Exa AI (Web Search & Knowledge)
- **Code Quality**: Biome (Linting/Formatting)

## 📂 Project Structure

### Core Directories
- `src/app/`: Next.js App Router pages and API routes.
  - `api/chat/`: Handles streaming chat completions and artifact processing.
  - `api/exa/`: Proxy for Exa web search capabilities.
  - `api/models/`: Fetches available AI models.
  - `api/tools/`: Manages tool execution (e.g., web searches).
  - `layout.js`: Root layout, global providers, and fonts.
  - `page.js`: Main chat application entry point and state management.
- `src/components/`: React components.
  - `chat/`: Core conversation UI (ChatInput, MessageList, ChatLayout, ArtifactPanel, etc.).
  - `layout/`: Layout wrappers (AppWrapper).
  - `ui/`: Low-level Shadcn UI primitives (Button, Card, Dialog, Input, etc.).
- `src/lib/`: Utility functions and client-side logic.
  - `api-client.js` / `exa-client.js`: API wrappers for chat and search.
  - `artifacts.js`: Logic for managing the "Artifacts" side panel.
  - `utils.js`: Tailwind class merging (cn) and helpers.

### Configuration Files
- `package.json`: Dependencies and scripts (`dev`, `build`, `start`, `lint`, `format`).
- `next.config.mjs`: Next.js configuration.
- `tailwind.config.js`: Styling configuration with custom typography and colors.
- `jsconfig.json`: Path aliasing (e.g., `@/*` maps to `./src/*`).

## 🧠 Key Architectural Concepts

### 1. Streaming Chat & Artifacts
The application uses a streaming response pattern. When the AI generates content meant for an "Artifact" (like code or a document), the client parses these instructions and renders them in the `ArtifactPanel`.

### 2. Web Search Integration (Exa)
The agent can perform web searches via the `/api/exa` routes. This is integrated into the chat flow, allowing the model to fetch real-time information using tools.

### 3. State Management & Persistence
- **Conversations**: Chat history is managed in the main page component and persisted via `localStorage`.
- **API Keys**: User-provided API keys for external services are stored securely in `localStorage`.

## 🛠 Development Workflow

### Getting Started
1. Install dependencies: `npm install`
2. Start development server: `npm run dev`

### Code Quality
- Use `npm run lint` to check for errors.
- Use `npm run format` to ensure consistent styling using Biome.

### Coding Guidelines
- **Component Pattern**: Use functional components with hooks. Follow Shadcn UI patterns for UI components.
- **API Communication**: Always use the abstractions in `src/lib/api-client.js` rather than raw `fetch` calls where possible.
- **Styling**: Use Tailwind CSS classes exclusively. Leverage the `cn()` utility for conditional classes.
- **Error Handling**: Ensure API routes return structured error messages that the client can parse via `getErrorMessage`.
